〔問30〕
※NASとHDD、NASとSANの違い
●NAS
：ネットワーク経由でアクセスできる共有ストレージ。
複数のデバイスでデータ共有・管理可能。
●HDD
：単体で使うローカルストレージ。
PCやゲーム機、録画機などに接続してデータ保存。

●NAS
：ファイル共有向けストレージ（複数のPCやデバイスで簡単に使える）
●SAN
：サーバー専用の高速ストレージ（エンタープライズ向け、大規模システム用）
●DAS
：サーバー・業務用の高速ストレージ（RAID対応・高性能）

※NASとNFSの違い
●NAS
：**ネットワーク経由で使うストレージ装置（ハード）**のこと
●NFS(Network File System)
：NASのようなストレージにアクセスするための通信のルール（ソフトウェアの仕組み）
※NASの中でNFSが使われていることもある

※NASとSANの違い
●NAS
：ファイル単位で共有し、同じフォルダに複数人でアクセス
●SAN
：ストレージ本体は共通だけど、アクセスする領域は個々に分ける（＝割り当てる）
→ サーバからは 自分専用のHDDのように見える。


＜NASのイメージ＞
┌─────┐
│ NAS  │ ← 共有フォルダ（例：\\nas\share）
└─────┘
   ↑ ↑ ↑
   │ │ │
UserA UserB UserC（みんなで同じ場所を使う）


＜SANのイメージ＞
┌────────────┐
│ SANストレージ │
└────────────┘
    ↑       ↑
  ServerA  ServerB（それぞれに専用の領域を割り当て）

→ ServerA：100GB  
→ ServerB：200GB  



〔問31〕
●シストリックアレイ
概要：演算装置（プロセッサ）が格子状に並び、データをリズムよく次々に渡して計算していく構造。
イメージ：「心臓（systolic）」のように、データを「ポンプのように」順々に送っていく感じ。
用途：AI（人工知能）や画像処理のような大量の計算を効率的に処理するのに使われる
●デスクトップグリッド
概要：世界中のPCの余っている計算能力を集めて、大きな処理を分担させる仕組み。
イメージ：たくさんの家のPCで一つの超大きな宿題を分けてやる、みたいな感じ。
例：有名な例は「SETI@home」などの科学プロジェクト。
●モノリシックカーネル
概要：OSのカーネル（中核部分）に、必要な機能（ファイル管理、デバイス制御など）が全部一体化している構造。
イメージ：大きな一枚岩のように、全部まとめて1つのまとまりで動く。
特徴：高速だが、修正や拡張がやや大変。
対比：モジュラー型やマイクロカーネル型は、機能を部品化して分けている。

〔問35〕
●待ち行列理論
：「サービスを待つ人や物が列を作る」現象を数学的に分析する理論

＜M/M/1モデルの前提条件＞
到着：ポアソン分布（平均到着率 λ）
サービス時間：指数分布（平均サービス率 μ）
1台のサーバーだけで処理

利用率（ρ）	ρ = λ / μ	サーバーが忙しい割合
系内の平均客数（L）	L = ρ / (1 − ρ)	システム内にいる平均人数
平均待ち行列長（Lq）	Lq = ρ² / (1 − ρ)	待ち行列に並ぶ平均人数
系内の平均時間（W）	W = 1 / (μ − λ)	システムに滞在する平均時間
平均待ち時間（Wq）	Wq = ρ / (μ − λ) = λ / (μ(μ−λ))	待ち行列での平均待ち時間

●デュアル構成
：2つのシステムを同時に稼働（負荷分散や冗長化）
●デュプレックス構成

〔問８〕
●2層クライアントサーバシステム
：クライアント（利用者）とサーバ（サービス提供者）に役割を分けたシステム構成
＜2層構成＞
クライアント層
　→ 画面表示やユーザーの操作、**一部の処理（ロジック）**を担当
　→ 例：アプリケーションソフト
サーバ層
　→ データベースを管理するデータベースサーバ（DBサーバ）
　→ クライアントからのリクエストに応じてデータを返す
＜3層構成＞
プレゼンテーション層（クライアント層）
　→ ユーザーと直接やり取りする部分（画面、入力）
　→ 例：Webブラウザやスマホアプリなど
アプリケーション層（ビジネスロジック層）
　→ データ処理や業務ロジックを担当
　→ 例：Webサーバ、アプリケーションサーバ（Java、PHPなどが動くところ）
データベース層
　→ データの保存・管理を行う
　→ 例：DBサーバ（MySQL、PostgreSQLなど）
